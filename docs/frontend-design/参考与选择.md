# 前端改版：参考与选择

状态：策划中，Linear 黑灰质感与左侧关卡叠层用途已获用户确认。完整设计初稿见同目录《前端页面策划案-v1.md》。Codex 负责设计与策划，swe2 负责后续实现。

## 已确认

- 深色为主，用户确认沿 Linear Features 首屏的黑灰明暗层次、表面边缘和文字质感细化。强调色与组件细节待选择。
- 带重量的轻回弹，允许明显的层次变化和转场。
- 原页面内做简短分层入场，不阻挡操作或拖延模型加载。
- 微调比例、间距、分组，保持当前操作顺序。
- 每一项视觉和组件决策均附具体示例；动效须有可体验链接。
- 用户确认 Aceternity 叠层用于左侧进入关卡任务、切换任务及返回列表。

## 选定后的交付格式

当前设计建议：以选中块连续移动和轻微按压回弹构成常用反馈；用户已确认面板叠层用于左侧关卡进入、切换与返回，具体力度由策划案规定首轮目标并在实现后验收。参考组件的紫色、粉色不构成配色承诺。

每个组件记录：原链接与版本/日期、具体观察点、用户取舍、目标页面位置、默认/悬停/按下/焦点/禁用/运行中/失败状态、动效节奏、连续点击时的处理、减少动态效果的表现、验收步骤。

## 注意事项

- 上述网站是视觉与行为参考，不意味着已决定引入对应组件库或复制源码；当前源码许可及接入兼容性本轮未核实。
- 页面已有三维渲染占用显卡，组件动效的性能需由实现阶段在真实页面验证。
- 保留模型、物理、关卡数据与功能；删除既有页面文字前须另列清单确认。
- 深色外框不等于修改模型光照；本轮没有更改应用代码或发布线上版本。
