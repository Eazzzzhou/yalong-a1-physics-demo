# 亚龙实验箱 · 网页演示

直接打开 GitHub Pages 首页进入完整版；`lite.html` 为轻量版。完整版使用 WebGPU（浏览器图形接口），设备不支持时自动进入 WebGL 2 轻量版。两版共用物理逻辑，默认场景为实拍铸造车间。

本目录是独立静态发布包，不需要本地接口、数据库或构建服务。可用 `python -m http.server 8020` 本地预览。模型不能通过双击 HTML 文件加载，需要通过网页服务器打开。

## 功能

- 关节按“从当前位置再转动”执行，屏幕先显示伪代码和编译状态，再运动。
- 76 个共享碰撞零件检查机械臂、面板、箱体、屏幕、固定模块和云台；相邻轴承连接件不互相阻挡。
- 遇到障碍或机械限位即停止；关卡显示实际转动量，屏幕区分编译失败和运动中断。
- 夹持采用有上限的软接触力、摩擦力和转动摩擦。方块保持独立动态刚体，无固定连接、瞬移或直接改写方块姿态。夹偏、接触丢失或超载会滑落。
- 三个方块依次取放，检查是否落在放置区。云台升起、复位和爆炸拆解继续可用；拆解期间暂停物理，重新执行前先收拢。
- 轻量版采用较小模型、环境图和贴图；完整版保留原有高写实材质、环境反射和后处理。

## 参数与边界

这是一套教学演示物理模型，参数不是实测硬件标定：每块方块 15 克，每侧最大夹紧力 1.2 牛，摩擦系数 0.8，接触垫 5×24×20 毫米，固定仿真步长 1/240 秒，关节最大速度 1.5 弧度/秒。输入时长过短时按速度上限延长，零时长也不能越过障碍。实际机械臂仍按受碰撞约束的角度轨迹驱动，未模拟电机电流、齿隙和全部关节动力学。

碰撞形状从完整版模型提取，零件使用独立凸形近似，不把整条机械臂包成一个实心物体。装配接缝允许 0.15 毫米数值容差；螺丝、线缆和细小孔洞不参与碰撞。夹爪内侧以软接触垫代替凸形包围面，保留抓取空隙。关卡中的“验证”是输入及执行检查，不是标准答案评分。
